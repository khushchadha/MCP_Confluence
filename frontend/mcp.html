MCP Server Tools

Call Confluence MCP tools directly — no agent involved.

search_pages GET Search Confluence pages by keyword or phrase
get_page GET Fetch the full content of a page by its ID
list_spaces GET List all available Confluence spaces
list_pages GET List the pages in a space, with their page IDs
create_page POST Create a new Confluence page in a space
update_page PUT Update an existing Confluence page by its ID
